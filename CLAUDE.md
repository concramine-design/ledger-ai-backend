- **`revision/` — « Mes révisions »** : le projet actif. Application locale (FastAPI + React) d'aide à la révision pour une
  élève marocaine de tronc commun. **Lis `revision/CLAUDE.md` avant toute chose** : tout le contexte y est
  (produit, architecture, décisions, façon de travailler avec le propriétaire, état d'avancement).
- **Racine (`server.js`, `api/`, `lib/`, `public/`)** : LEDGER, une ancienne application de suivi d’habitudes, qui n’est plus développée.
  Le `README.md` de la racine parle de LEDGER, pas de « Mes révisions ».

Le travail sur « Mes révisions » se fait sur la branche `claude/revision-app-tronc-commun-cfrhnk`
(tant qu'elle n'est pas fusionnée dans `main`, une session qui démarre sur `main` ne voit pas le dossier `revision/`).
